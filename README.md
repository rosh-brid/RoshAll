# RoshAll

RoshAll is a collection of Android applications and reusable libraries developed under the Rosh project.

The project is designed as a modular Android environment where different tools and applications can be developed, tested, and maintained as separate modules while sharing a common library and architecture.

Modules

- Rosh — Main application that brings the Rosh tools together.
- Berkas — File management and storage utilities.
- Browser — Lightweight web browsing using Android WebView.
- Code — Code editor and development tools.
- Terminal — Terminal and shell-related tools.
- Gambar — Image viewing and media-related functionality.
- Lib — Shared Rosh libraries and reusable Android components.

RoshAll is continuously developed with a focus on modularity, simplicity, and practical Android tools.
